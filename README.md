# Chemistry for Grade 9

This is a simple website to help grade 9 students learn about chemistry. It includes learning materials and practice questions for Unit 1: Matter and its Compositions.

## Manual Deployment to GitHub Pages

To deploy this website to GitHub Pages, follow these steps:

1.  **Install Dependencies:**
    - Run `npm install` in your terminal to install the necessary development dependencies.

2.  **Deploy to GitHub Pages:**
    - Run `npm run deploy` in your terminal. This command will automatically create a `gh-pages` branch (if it doesn't exist) and push the necessary files to it.

3.  **Configure GitHub Pages:**
    - Go to your repository's settings on GitHub.
    - Scroll down to the "GitHub Pages" section.
    - Select the `gh-pages` branch as the source and save.
    - Your website will be live at the URL specified in the `homepage` field of your `package.json` file.
