Unit 2: The Periodic Table

Introduction to the Periodic Table

The Periodic Table is a chart that organizes all the known elements in order of increasing atomic number. It is one of the most important tools in chemistry, providing a wealth of information about each element.

How to Read the Periodic Table

Each box in the periodic table represents an element and contains key information:

  • Atomic Number: The number of protons in an atom of the element.
  • Symbol: A one or two-letter abbreviation for the element.
  • Name: The full name of the element.
  • Atomic Mass: The average mass of an atom of the element.

Periods and Groups

The periodic table is organized into rows and columns:

  • Periods: The horizontal rows (from left to right) are called periods. Elements in the same period have the same number of electron shells.
  • Groups: The vertical columns (from top to bottom) are called groups or families. Elements in the same group have similar chemical properties because they have the same number of valence electrons (electrons in the outer shell).
