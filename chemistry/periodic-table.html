Unit 2: The Periodic Table

Introduction to the Periodic Table

The Periodic Table is a chart that organizes all the known elements in order of increasing atomic number. It is one of the most important tools in chemistry, providing a wealth of information about each element.

What's an Element?

An element is a substance made of one type of atom, defined by its number of protons. For example, hydrogen has 1 proton, while helium has 2. Most substances on Earth are compounds, which are combinations of elements, but some elements, like gold, can be found in their pure form.

How to Read the Periodic Table

Each box in the periodic table represents an element and contains key information:

  • Atomic Number: The number of protons in an atom of the element.
  • Symbol: A one or two-letter abbreviation for the element.
  • Name: The full name of the element.
  • Atomic Mass: The average mass of an atom of the element.

Periods and Groups

The periodic table is organized into rows and columns:

  • Periods: The horizontal rows (from left to right) are called periods. Elements in the same period have the same number of electron shells, and their properties change gradually across the row. Metals are typically found on the left, while non-metals are on the right.
  • Groups: The vertical columns (from top to bottom) are called groups or families. There are 18 groups in total. Elements in the same group have similar chemical properties because they have the same number of valence electrons (electrons in the outer shell).

A Brief History of the Periodic Table

The modern periodic table was created by Dmitri Mendeleev in 1869, but he wasn’t the first to try organising the elements. In 1789, Antoine Lavoisier grouped elements into basic categories, and in 1862, Alexandre-Émile Béguyer de Chancourtois arranged them by atomic weight in a spiral shape, noticing that properties repeated in patterns. Later, John Newlands introduced the Law of Octaves, where every eighth element shared similar properties.

Mendeleev's version, however, was unique because he left intentional gaps for undiscovered elements, and his predictions proved to be correct. It wasn't until the 1950s that the table was reorganized based on atomic number and electronic configuration, giving us the version we use today.
